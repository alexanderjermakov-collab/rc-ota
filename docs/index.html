For SHARP remotes with the Telink Legacy OTA service, including AN2303B-2UM-001. The live model, battery and OTA characteristic are checked before installation; the file must be intended for this exact model and bootloader. AN2303B transfer has not yet been tested on hardware.

Direct server preparation requires the manufacturer to allow browser access (CORS). If blocked, use the Windows app, or download a BIN and select it locally.
