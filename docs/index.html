Help

Use Chrome on Android with Bluetooth enabled.

How to update your remote

  1. Wake the remote, press Connect and select it. Its information is read automatically. Read refreshes the current information.
  2. Choose From phone for a local BIN, or From server. If the server downloads a BIN separately, select the saved file with From phone.
  3. Confirm that the file is for your exact remote model, then press Update remote.
  4. Keep the remote nearby and this page open until the result appears. The remote restarts during an update.

Battery: at least 30%. Local BINs allow upgrade, downgrade or reinstall. The filename must identify your exact remote model.

If the remote disconnects after restarting, wake it and press Connect. Choosing it again in Chrome does not by itself mean system pairing was lost.

Troubleshooting
