About

RC OTA · SHARP

Версия 0.13.0

Чтение данных и обновление пульта через Bluetooth. Для Chrome на Android.

Файл поможет специалисту разобраться с ошибкой.

Как обновить пульт

  1. Включите Bluetooth. Разбудите пульт, нажмите Подключить и выберите его.
  2. Выберите прошивку С телефона или С сервера. Если BIN скачался отдельно, выберите его через С телефона.
  3. Подтвердите, что файл подходит вашей модели, и нажмите Обновить пульт.
  4. Держите пульт рядом, не закрывайте страницу и дождитесь результата. Кнопка Считать обновляет данные.

Заряд — от 30%. Используйте BIN для своей модели. Локально доступны обновление, даунгрейд и переустановка.
