Help

Use Chrome on Android with Bluetooth enabled.

Pair the remote with the phone

  1. Turn on Bluetooth on the phone and open Android Bluetooth settings.
  2. Press and hold Back and Home together on the remote for 3 seconds, until the red LED starts flashing.
  3. Select SHARP RCU or SHARP SOLAR RCU in Android and confirm Pair. If it is already paired, keep the existing pairing.
  4. Return to this page in Chrome. Press Connect, select that remote and allow access. Wait for its exact model, version and battery to appear. Selecting a device alone is not a completed connection.

Select the firmware

  1. Press From phone and choose the BIN for the exact displayed model. AN2303-2UM-001 and AN2303B-2UM-001 require different files.
  2. Or press From server. If Chrome blocks the server download, use the displayed download link, save the BIN and select it with From phone. The AN2303 manufacturer filename is accepted unchanged only when its catalogue checksum matches.
  3. Wait until the file is ready. Confirm it once. The BIN and confirmation are kept for the next units of the same model.

Upgrade the remote

  1. Press Update remote. Keep the remote powered and nearby; leave this page open.
  2. Wait for the transfer to finish. At 100% the bytes have been sent; that alone does not confirm installation.
  3. There are no automatic reconnection attempts. If the remote restarts and disconnects, wake it, repeat Back + Home for 3 seconds if pairing is needed, then press Reconnect and select the same remote to read its installed version.
  4. For another unit, press Next remote and repeat steps 1–4. The retained matching BIN is prepared automatically; press Update remote.

Battery: at least 30%. Local BINs allow upgrade, downgrade or reinstall; server firmware must be newer. The BIN is retained in this browser when local storage is available. Each remote still needs a separate Update remote press.

Forget closes the connection and revokes this website’s permission when Chrome supports it. It cannot remove Android system pairing: use Android Bluetooth settings for that. Chrome requires you to select each new physical remote once.

Forget does not delete Android pairing. After Forget, Connect opens a fresh device chooser. If Android pairing is stale, remove only that remote in Android Bluetooth settings and repeat steps 1–4.

Troubleshooting

Save a report with remote information and the activity log for support.
